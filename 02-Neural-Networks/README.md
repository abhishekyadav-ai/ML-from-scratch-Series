# Neural Networks From Scratch

A collection of step-by-step implementations of neural network building blocks using Python and NumPy.

Each notebook focuses on implementing a core component from first principles to understand the mathematics and programming behind neural networks without relying on deep learning frameworks.

## Topics Covered

- ✅ Single Neuron
- ✅ Multiple Neurons
- ✅ Layers of Neurons
- ✅ Matrix Multiplication using NumPy
- ✅ Batch Processing
- ✅ Dense Layer Class
- ✅ Forward Pass
- ✅ ReLU Activation Function
- ✅ Softmax Activation Function
